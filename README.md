# Airline Review Topics

This repository contains a static presentation generated from `tabla.xlsx`.

## How to publish it on GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html`, `tabla.xlsx`, and this `README.md`.
3. Open the repository settings.
4. Go to **Pages**.
5. In **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the root folder `/`.
7. Save the settings.

GitHub will create a public URL for the presentation after the first deployment finishes.

## Files

- `index.html`: interactive public presentation.
- `tabla.xlsx`: original Excel source.
- `README.md`: publication instructions.
